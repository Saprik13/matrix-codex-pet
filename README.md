# Matrix Codex Pet

Source artifacts, generated animation frames, QA reports, and the packaged
Codex v2 pet for Matrix Codex.

## Project layout

- `pet-runs/matrix-codex-v2/` — generation inputs, prompts, frames, QA
  artifacts, final spritesheets, and the installable package.
- `matrix-codex-existing-validation.json` — validation result captured before
  chroma cleanup.
- `matrix-codex-existing-validation-magenta.json` — validation result captured
  after chroma cleanup.

The ready-to-install package is in
`pet-runs/matrix-codex-v2/package/matrix-codex/`.
